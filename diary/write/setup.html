A place to write.

The editor saves your entries directly to GitHub. Once connected, you can write from your computer or phone without opening a code editor.

Connect your GitHub account

  1. Open GitHub’s fine-grained token settings. Name it “Personal diary” and choose an expiration date.
  2. Set the resource owner to yasulin. Under “Only select repositories”, choose yasulin.github.io.
  3. Under repository permissions, give Contents: Read and write. Metadata read access is included automatically. No other permissions are needed.
  4. Create the token, then open the diary editor, choose Sign In Using Access Token, and paste it there.

The editor remembers the token in this browser. Use your own device and sign out on shared devices. When the token expires, create a replacement. Keep the token out of diary entries and source files.

Write and publish

Choose Diary, create an entry, pick a date, and write. Saving publishes it to the public GitHub repository; the website updates after its deployment finishes. To revise an existing day, open that entry from the list.

Entries are public when saved. This editor is for your public diary.
